# perf test cases

Generated by `uv run python cases/run_all.py --md` on Python 3.13.13 (Linux): **39 cases, 391 checks, 0 failing** (9 not applicable on this Python version — see each check's *(Python …)* scope).

Every check runs the case script in its own interpreter, then asserts on the trace JSON it wrote (or on its stdout). Status meanings:

- `works`: perf traces and captures this as you'd expect.
- `limitation`: a known blind spot or lossy representation; the check pins down exactly what you get instead.
- `bug`: known wrong behaviour; the check fails once it is fixed, so update it then.

Assertions: names are fnmatch patterns; a path is a chain of direct children starting at the root; values are compared after resolving `{"__ref__"}` pool refs (unless marked); `*` inside an expected string is a wildcard; `"...": true` in an expected dict allows extra keys.

### New limitations documented (5)

Known gaps the new cases pinned down; each needs a decision (accept, document in the skill, or fix):

- [c11_rebinding](#c11_rebinding): a replacement bound DURING the trace is not instrumented until the next trace (the new function object was never patched)
- [c14_threads](#c14_threads): a thread whose ENTRY point is library code (here Thread(target=sorted, key=project_fn)) does not inherit the trace: project calls it makes are not recorded — such threads are usually long-lived workers that must not attach unrelated work to this trace
- [c15_worker_failure](#c15_worker_failure): the dead worker's own subtree is lost (it never got to send it back)
- [c16_config_interactions](#c16_config_interactions): SKIP_VARIABLES drops values by NAME only, so it can't scrub text: a secret inside an exception message is still recorded — use REDACT_PATTERNS for that (below)
- [c20_misc_shapes](#c20_misc_shapes): patching REBINDS every module-level name bound to a project function (its own name, aliases, any global variable holding it): a reference taken before the trace is no longer `is`-identical to that global while tracing (identity checks like `cb is mod.handler` change result)
